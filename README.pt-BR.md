## Pré-requisitos

- [Node.js](https://nodejs.org/) 18+
- [Claude Code](https://github.com/anthropics/claude-code) instalado globalmente
- **Windows** 10 ou 11
- **macOS** 12+ (Intel ou Apple Silicon)
- **Linux** Ubuntu 22.04+, Fedora 38+ ou equivalente
  - O AppImage exige `libfuse2` no Ubuntu 24.04+: `sudo apt install libfuse2`
  - O armazenamento do token do GitHub exige `libsecret`: `sudo apt install libsecret-1-dev gnome-keyring`

## Instalação

Baixe o instalador mais recente em [Releases](https://github.com/Sterll/claude-terminal/releases).

> [!IMPORTANT]
> **Usuários de macOS:** se aparecer *"Claude Terminal is damaged and can't be opened"*, execute isto no Terminal:
> ```bash
> xattr -cr /Applications/Claude\ Terminal.app
> ```
> Isso é necessário porque o app ainda não tem assinatura de código. Como alternativa, clique com o botão direito no app → Abrir.

Ou compile a partir do código-fonte:

```bash
git clone https://github.com/Sterll/claude-terminal.git
cd claude-terminal
npm install
```

## Funcionalidades

### Interface de chat (Claude Agent SDK)
- Interface de chat integrada, baseada no Claude Agent SDK, com respostas em streaming
- Fechar uma aba de chat cancela a inicialização pendente e encerra a sessão do SDK; prompts atrasados não conseguem reabrir uma aba fechada.
- **Renderização rica de markdown**: diagramas mermaid, matemática KaTeX, código com realce de sintaxe, árvores de arquivos, quadros kanban, blocos de diff, pré-visualizações HTML e mais
- **Cartões de permissão**: Permitir, Sempre permitir ou Negar pedidos de uso de ferramentas; quando uma das suas próprias regras `permissions.ask` dispara o pedido, o cartão cita essa regra e esconde o Sempre permitir, para que ela não seja descartada com um clique
- **Modo de planejamento**: revise e aprove/rejeite os planos do agente antes da execução
- **Blocos de raciocínio**: seções expansíveis que mostram o raciocínio do Claude
- **Cartões de ferramenta**: cartões recolhíveis que mostram a execução das ferramentas com detalhes formatados, incluindo atualização de ferramentas MCP, envio de feedback e ações de proposta de skill
- **Visualização de subagentes**: acompanhamento aninhado das tarefas dos agentes criados, com o resumo de cada subagente mostrando o branch do seu git worktree e qualquer troca de modelo durante a execução
- **Widget de tarefas**: lista de tarefas persistente acima do campo de entrada, que some sozinha ao concluir
- **Anexos**: cole, arraste e solte ou escolha imagens PNG/JPEG/GIF/WebP (até 20MB), além de arquivos de texto e PDFs
- **Comandos de barra**: comandos com autocompletar (/compact, /clear, /help, skills personalizadas)
- **@menções inline**: o campo de entrada contenteditable permite digitar @menções inline sem sair da área de composição da mensagem
- **Retrocesso de arquivos**: reverta o contexto do chat para um estado anterior dos arquivos via checkpoints do SDK, útil para desfazer edições indesejadas no meio da sessão
- **Controle de custos**: nome do modelo, contagem de tokens e custo em USD na barra de status
- **Janela de contexto de 1M**: contexto estendido para bases de código maiores (somente no modo API)
- **Troca dinâmica de modelo e esforço**: o seletor de modelo é montado em tempo real a partir do catálogo do próprio Claude CLI, então modelos recém-lançados (por exemplo, Fable 5.1) aparecem automaticamente; troque o modelo e o nível de esforço (low, medium, high, xhigh) no meio da conversa sem abrir uma nova sessão
- **Modelo, esforço e modo de permissão por conversa**: cada aba guarda suas próprias configurações, então uma escolha em uma conversa nunca vaza para a próxima. Os valores salvos são apenas os padrões com que uma nova aba começa, alterados pela linha "Usar em novas conversas" de cada menu
- **Modos de permissão**: alterne entre padrão, aceitar edições, planejamento e ignorar permissões direto do compositor, no meio da sessão
- **Nível de modelo Premium**: os modelos da família Fable são destacados em violeta com um selo "Premium", uma marcação na aba e um aviso quando uma nova aba herda um deles, porque a família consome seu próprio limite de uso
- **Gaveta de tarefas em segundo plano**: uma gaveta recolhível, restrita à sessão atual, mostra o que o Claude está executando em segundo plano, para você continuar conversando enquanto ele termina
- **Biblioteca de artefatos e aba Documentos**: arquivos e trechos gerados pelo Claude são salvos em uma biblioteca de artefatos reutilizável e também aparecem em uma aba Documentos por conversa para acesso rápido, com um painel Artefatos dedicado listando tudo o que foi publicado para o projeto
- **Busca na conversa**: pressione Ctrl+F para buscar na transcrição da conversa atual
- **Fixar conversas**: mantenha sessões importantes no topo da lista
- **Bifurcar sessões**: crie um ramo a partir de qualquer mensagem para explorar caminhos alternativos; o Claude Terminal avisa em vez de descartar se um turno na fila fosse ser perdido
- **Sugestões de continuação**: chips de sugestão sensíveis ao contexto aparecem depois que o Claude responde, para ajudar a guiar a conversa
- **Resumos de sessão**: resumos gerados automaticamente por IA das sessões concluídas
- Digite @project para anexar o README.md e a árvore de arquivos de qualquer projeto como contexto
- Digite **@tab** para compartilhar sua sessão de terminal atual ou **@conversation** para referenciar outra conversa
- Digite **@context** para injetar um pacote de contexto ou **@prompt** para inserir um modelo de prompt salvo direto na sua mensagem
- **Aprimoramento de prompt**: reescrita da sua mensagem por IA com um clique, usando o Haiku, para instruções mais claras antes de enviar
- Interrompa o streaming no meio do turno; nomes de abas gerados automaticamente pelo modelo haiku
- Indicador de compactação exibido durante a compactação da conversa, para você saber quando o contexto está sendo comprimido

### Terminais
- Vários terminais Claude Code por projeto, com interface em abas
- Renderização acelerada por GPU via xterm.js + WebGL (com fallback para DOM)
- Alterne entre modo terminal e modo chat em cada aba
- Reordenação de abas por arrastar e soltar, renomeação, notificações na área de trabalho
- Filtre terminais por projeto
- Detecção adaptativa de prontidão com status em spinner
- Saída do terminal capturada, para que as ferramentas de leitura de terminal e as ferramentas MCP realmente retornem o que foi executado

### Navegação
- Escolha como navegar pelos projetos: uma barra de abas de projeto no topo ou uma coluna clássica de projetos na lateral
- Perguntado uma vez no assistente de configuração inicial, e alterável a qualquer momento nas Configurações

### Arquivos
- Uma tela Arquivos dedicada mostra cada arquivo tocado em uma sessão, com diffs por sessão renderizados no estilo do GitHub
- Revise rapidamente o que o Claude mudou sem sair do contexto do chat
- Ou mantenha a árvore do projeto encaixada ao lado da conversa, como era antes da tela Arquivos

### Contas
- Vincule uma conta Claude separada a cada projeto, com seu próprio armazenamento de credenciais isolado
- Troque de projeto sem trocar de conta manualmente, e sem que o login de um projeto afete o de outro
- Uso por conta exibido nas Configurações, e uma troca por limite de uso que leva a conversa junto

### Claude Remote Control (claude.ai e celular)
- Coloque uma sessão de chat no [claude.ai/code](https://claude.ai/code) e no app móvel do Claude, para acompanhá-la ou conduzi-la pelo celular
- Decidido **por conversa**, nunca globalmente: uma sessão entra quando você pede naquela aba, pelo botão do rodapé ou pelo comando `/remote-control`
- Espelho somente leitura ou controle total, você escolhe; prompts, interrupções e respostas de permissão voltam todos para o desktop
- `--rc` opcional nas abas de terminal para que as sessões do CLI também entrem
- Uma aba **Conectividade → claude.ai** lista cada conversa compartilhada, com um caminho de volta para cada aba
- Respeita a chave de desligamento `disableRemoteControl` das configurações gerenciadas do Claude Code, para que uma política da organização não possa ser suspensa pelo app

### Claude in Chrome
- Permita que as sessões de chat controlem seu navegador pela extensão Claude para Chrome
- Adiciona à sessão o servidor MCP `claude-in-chrome` e suas 22 ferramentas de navegador
- Opcional, e adota o native messaging host já existente do Claude Code em vez de sobrescrevê-lo

### Voz
- Dite mensagens para o campo do chat pelo microfone (transcrição via Groq)
- Modo de ditado literal com roteamento para a aba em foco, para que suas palavras caiam na conversa certa
- Perfil de sessão mãos-livres para sessões totalmente guiadas por voz
- Pronuncia os nomes dos projetos do jeito que você os diria, para que as @menções por voz sejam resolvidas corretamente

### Gerenciamento de projetos
- Organize projetos em pastas aninhadas com arrastar e soltar
- Personalize cada projeto com cores e ícones emoji
- Barra de Ações rápidas: comandos de um clique configuráveis por projeto (build, test, deploy, scripts personalizados...)
- Explorador de arquivos integrado com visualização em árvore, seleção múltipla, busca, indicadores de status do git e renomeação inline; clique com o botão direito em qualquer arquivo para anexá-lo como contexto no chat atual
- Sistema modular de tipos de projeto (padrão, FiveM, webapp, Python, API, Minecraft, bot do Discord)
- Modal de configurações por projeto

### Integração com Git
- **Branches**: alterne, crie e exclua, com visualização em árvore dos branches locais/remotos
- **Sincronização**: pull (rebase), push, merge com detecção e resolução de conflitos
- **Painel de alterações**: veja arquivos staged/unstaged/untracked, faça stage/unstage e commit
- **Histórico de commits**: grafo de commits no estilo IntelliJ com renderização SVG, filtro por branch/autor, rolagem infinita
- **Cherry-pick e revert**: operações avançadas de commit a partir do histórico
- **Gerenciamento de worktrees**: crie, alterne e exclua Git worktrees, com um selo de troca rápida na barra de ferramentas
- **Gerenciamento de stash**: salve, aplique, faça pop e inspecione stashes
- **Busca no histórico**: busca de texto completo no histórico de commits
- **Descartar alterações**: descarte rapidamente edições unstaged por arquivo
- **Amend de commits**: edite a mensagem ou o conteúdo staged do último commit antes do push
- **Mensagens de commit com IA**: gere automaticamente mensagens de commit convencionais via GitHub Models API
- **Pull Requests**: crie e visualize PRs direto do app

### Integração com GitHub
- Autenticação por OAuth Device Flow (segura, sem copiar e colar token)
- **Suporte ao GitHub Enterprise**: conecte-se a instâncias auto-hospedadas do GitHub Enterprise
- **Busca de repositórios no assistente de clone**: busque repositórios do GitHub pelo nome sem sair do app
- **Pílula de status de CI/CD**: status em tempo real da última execução de workflow, exibido direto na barra de cabeçalho do terminal, com um botão Corrigir para ir direto à etapa que falhou
- Veja as execuções de workflows de CI/CD por repositório
- Veja, crie e revise pull requests pelo app; suporte a várias forjas (GitHub, GitLab)
- Token armazenado com segurança via keytar (Windows Credential Manager, macOS Keychain, Linux libsecret)

### Control Tower
- Visão geral em tempo real de todos os agentes Claude ativos em todos os projetos
- Veja o que cada agente está fazendo (ferramentas em execução, status atual, última atividade)
- Visão em grade: um cartão por sessão aberta, agrupado por projeto, com miniaturas do terminal ao vivo, selo do modelo e botões de nova sessão por projeto
- Filtros e ordenação: por projeto, por status, busca por texto, ordenado pela sua última interação
- Visão em foco: maximize qualquer sessão dentro do painel com uma tira das outras sessões do projeto, títulos de sessão editáveis e salto com um clique para a visão do Claude
- Sessões concluídas continuam destacadas até você vê-las, para que nenhum trabalho terminado passe despercebido
- Interrompa qualquer sessão em execução direto do painel
- Responda a prompts AskUserQuestion sem mudar para a aba do chat
- Ferramentas MCP para monitoramento de agentes e interrupção remota

### Tarefas paralelas
- Decomponha uma funcionalidade em subtarefas paralelas e execute-as simultaneamente como agentes Claude separados
- Cada tarefa roda no seu próprio Git worktree e branch, mantendo o trabalho isolado
- O modo automático deixa o Claude decidir o número ideal de tarefas paralelas
- Cartões de tarefa recolhíveis com visualizador de diff e acesso ao terminal por tarefa
- Agente de auto-merge: o Claude revisa e faz merge dos branches concluídos no seu branch principal
- Estado completo da execução persistido em disco e restaurado ao reiniciar o app

### Replay de sessões
- Navegue pelas sessões anteriores do Claude Code e reproduza-as passo a passo
- A linha do tempo mostra todos os prompts, chamadas de ferramentas e respostas em ordem cronológica
- Barra de rolagem no estilo de player de vídeo para saltar para qualquer ponto da sessão
- Cartões de perguntas e respostas destacam as trocas de pergunta e resposta para facilitar a revisão

### Painel
- Abra o projeto selecionado direto pela barra superior; ações e dados em cache aparecem imediatamente enquanto Git, estatísticas de código e dados do GitHub carregam progressivamente
- Três subvisões: **Visão geral**, **Kanban** e **Linha do tempo**
- Visão geral: branch atual, commits à frente/atrás, commits recentes, contribuidores
- Estatísticas de código: linhas de código por linguagem, número de arquivos, número de commits
- Contagem de terminais ativos
- Monitoramento de uso da API do Claude com atualização automática
- **Linha do tempo do projeto**: todos os registros que o app já mantém, reunidos em uma única visão cronológica — commits, sessões do Claude, tempo registrado, execuções de workflows, execuções paralelas e artefatos — filtrável por período e por tipo, para que "o que aconteceu com este projeto" seja uma tela em vez de seis

### Controle de tempo
- Detecção automática de sessões por projeto (tempo de inatividade de 15 min, detecção de suspensão/retomada)
- Armazenamento leve separado (`timetracking.json`) com arquivos mensais
- Visualização por período: hoje, esta semana, este mês, intervalo personalizado
- Estatísticas: média diária, maior sequência, gráficos de evolução, sessões recentes
- Virada à meia-noite e checkpoints periódicos

### Hooks
- Integração com os hooks do Claude Code CLI para acompanhamento de atividade em tempo real
- Instalação com um clique em `~/.claude/settings.json` (não destrutiva, preserva os hooks do usuário)
- Tipos de hook: PreToolUse, PostToolUse, Notification, SessionStart, Stop, DirectoryAdded (disparado em `/add-dir`) e mais
- Barramento de eventos com eventos normalizados para acompanhamento de sessões, ferramentas e subagentes
- Leitura da saída do terminal como alternativa quando os hooks não estão disponíveis

### Plugins
- Navegue e descubra plugins dos marketplaces configurados
- Instale plugins direto pelo app (via Claude CLI)
- Adicione marketplaces da comunidade pela URL do GitHub
- Filtro por categoria e busca
- Veja os detalhes e o README dos plugins

### Marketplace de skills
- Busque e navegue pelas skills disponíveis
- Instalação e desinstalação com um clique
- **Verificação de atualizações**: veja quais skills e plugins instalados têm novas versões disponíveis
- Veja o README e os detalhes das skills
- Cache local para navegação rápida

### Biblioteca
- Gerencie **pacotes de contexto** reutilizáveis (documentos, trechos, conteúdo de arquivos) e **modelos de prompt**
- Injete pacotes de contexto ou modelos de prompt direto no chat pelas menções @context e @prompt
- Insira modelos de prompt em qualquer terminal com um clique pela barra de ferramentas
- Gere skills e agentes em segundo plano usando o Agent SDK

### Skills e agentes
- Navegue e gerencie skills e agentes do Claude Code
- Veja os arquivos SKILL.md e de configuração dos agentes
- **Editor com realce de sintaxe**: edite arquivos de skills e agentes com números de linha e realce de código completo via highlight.js
- Carregue skills de `~/.claude/skills`, de plugins e de recursos embutidos

### Servidores MCP
- Configure, inicie e pare servidores MCP
- Configuração de variáveis de ambiente
- **MCP Registry**: navegue e busque no registro público de servidores MCP

### Sessões
- Veja as sessões do Claude Code por projeto
- Navegue pelo histórico de sessões com datas e metadados
- Fixe sessões no topo e renomeie-as inline pelo diálogo de retomada
- Modal de retomada de sessão modernizado, com busca e sessões fixadas
- As sessões mostram o título real da conversa em vez de uma data, e podem ser buscadas pelo id
- **Mover uma sessão para outro projeto**: realoque uma conversa sem perder o histórico
- Nomes de abas personalizados ficam travados e não são mais sobrescritos silenciosamente pela nomeação automática

### Memória e conhecimento global
- Edite os arquivos CLAUDE.md globais, de configurações e específicos de cada projeto
- Inserção de modelos para padrões comuns
- **Conhecimento global**: um repositório de fatos, convenções e preferências entre projetos, uma entrada markdown para cada, disponível em todas as sessões

## Testes

```bash
# Run the test suite (149 Jest suites, jsdom)
npm test

# Watch tests during development
npm run test:watch

# ESLint over main, renderer, shared, MCP servers and scripts
npm run lint
npm run lint:fix

# Fail if CLAUDE.md has drifted from the tree it describes
npm run check:docs

# Playwright smoke test against the real Electron app
npm run test:e2e
```

A CI executa três jobs a cada push e PR: `lint` (rápido, falha primeiro), `test` (Node 18
e 20 no Windows, Linux e macOS) e `e2e` (Ubuntu sob `xvfb-run`). O job E2E é
**bloqueante**: ele abre o app real, percorre cada aba da barra lateral e falha em qualquer
erro no console do renderer ou crash do processo principal.

`npm run test:e2e` fica fora do `npm test` porque precisa de uma tela e de um bundle do
renderer já compilado. Executá-lo localmente também exige os módulos nativos compilados
para a ABI do Electron (`npm run postinstall`).

### Fronteiras

A separação entre main e renderer é garantida pelo ESLint, não apenas por convenção:

- O renderer nunca recebe `child_process`, `fs`, `net` ou `electron` diretamente. Ele se
  comunica com o main apenas por `window.electron_api`. **`child_process` nunca é exposto
  de propósito** — o renderer exibe markdown escrito pelo modelo, então uma ponte para
  criação de processos transformaria qualquer injeção de HTML em execução de código.
- `contextIsolation: true` e `nodeIntegration: false` nas cinco janelas.
- A CSP do `index.html` não tem `'unsafe-inline'`, então HTML injetado no chat
  não consegue executar scripts. Todo markdown renderizado para o usuário passa pelo `dompurify`.

Se uma regra de fronteira disparar, a correção é um novo handler IPC, não um `eslint-disable`.
