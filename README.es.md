## Requisitos previos

- [Node.js](https://nodejs.org/) 18+
- [Claude Code](https://github.com/anthropics/claude-code) instalado globalmente
- **Windows** 10 u 11
- **macOS** 12+ (Intel o Apple Silicon)
- **Linux** Ubuntu 22.04+, Fedora 38+ o equivalente
  - La AppImage necesita `libfuse2` en Ubuntu 24.04+: `sudo apt install libfuse2`
  - El almacenamiento del token de GitHub necesita `libsecret`: `sudo apt install libsecret-1-dev gnome-keyring`

## Instalación

Descarga el último instalador desde [Releases](https://github.com/Sterll/claude-terminal/releases).

> [!IMPORTANT]
> **Usuarios de macOS:** si ves *«Claude Terminal está dañado y no se puede abrir»*, ejecuta esto en la Terminal:
> ```bash
> xattr -cr /Applications/Claude\ Terminal.app
> ```
> Hace falta porque la aplicación aún no está firmada. Como alternativa, clic derecho en la app → Abrir.

O compila desde el código fuente:

```bash
git clone https://github.com/Sterll/claude-terminal.git
cd claude-terminal
npm install
```

## Funcionalidades

### Interfaz de chat (Claude Agent SDK)
- Interfaz de chat integrada, impulsada por el Claude Agent SDK, con respuestas en streaming
- **Renderizado markdown enriquecido**: diagramas mermaid, fórmulas KaTeX, código con resaltado de sintaxis, árboles de archivos, tableros kanban, bloques de diff, vistas previas HTML y más
- **Tarjetas de permiso**: Permitir, Permitir siempre o Denegar las solicitudes de uso de herramientas; cuando es una de tus propias reglas `permissions.ask` la que dispara la solicitud, la tarjeta nombra esa regla y oculta «Permitir siempre» para que no se pueda saltar de un clic
- **Modo plan**: revisa y aprueba o rechaza los planes del agente antes de ejecutarlos
- **Bloques de razonamiento**: secciones desplegables que muestran el razonamiento de Claude
- **Tarjetas de herramientas**: tarjetas plegables que detallan la ejecución de las herramientas, con recarga de herramientas MCP, envío de comentarios y propuestas de skills
- **Visualización de subagentes**: seguimiento anidado de las tareas delegadas; el resumen de cada subagente muestra su rama de worktree de git y cualquier cambio de modelo a mitad de camino
- **Widget de tareas**: lista de tareas persistente encima de la entrada, que desaparece sola al completarse
- **Adjuntos**: pegar, arrastrar y soltar o elegir imágenes PNG/JPEG/GIF/WebP (hasta 20 MB), además de archivos de texto y PDF
- **Comandos slash**: autocompletado de comandos (/compact, /clear, /help, skills personalizados)
- **Menciones @ en línea**: el campo de entrada enriquecido permite escribir menciones @ sin salir del área de redacción
- **Rewind de archivos**: vuelve a un estado anterior de los archivos mediante el checkpointing del SDK, útil para deshacer ediciones no deseadas a mitad de sesión
- **Seguimiento de costes**: nombre del modelo, número de tokens y coste en USD en la barra de estado
- **Ventana de contexto de 1M**: contexto ampliado para bases de código grandes (solo en modo API)
- **Cambio dinámico de modelo y esfuerzo**: el selector de modelo se construye en vivo desde el catálogo del propio CLI de Claude, así que los modelos recién lanzados (por ejemplo Fable 5.1) aparecen automáticamente; cambia de modelo y de nivel de esfuerzo (low, medium, high, xhigh) a mitad de conversación sin empezar de nuevo
- **Modelo, esfuerzo y modo de permiso por conversación**: cada pestaña guarda sus propios ajustes, así que una elección en una conversación nunca se filtra a la siguiente. Los valores guardados son solo los predeterminados con los que arranca una pestaña nueva, y se cambian desde la fila «Usar para conversaciones nuevas» de cada menú
- **Modos de permiso**: alterna entre predeterminado, aceptar ediciones, plan y omitir permisos desde el compositor, a mitad de sesión
- **Nivel premium**: los modelos de la familia Fable se marcan en violeta con una insignia «Premium», una etiqueta en la pestaña y un aviso cuando una pestaña nueva lo hereda, porque esa familia consume su propio límite de uso
- **Cajón de tareas en segundo plano**: un cajón plegable, propio de la sesión actual, muestra lo que Claude ejecuta en segundo plano para que puedas seguir conversando
- **Biblioteca de artefactos y pestaña Documentos**: los archivos y fragmentos que Claude genera se guardan en una biblioteca reutilizable y también aparecen en una pestaña Documentos propia de la conversación, con un panel Artefactos dedicado que lista todo lo publicado para el proyecto
- **Búsqueda en la conversación**: pulsa Ctrl+F para buscar en la transcripción actual
- **Fijar conversaciones**: mantén las sesiones importantes al principio de la lista
- **Bifurcar sesiones**: parte desde cualquier mensaje para explorar caminos alternativos; Claude Terminal avisa en lugar de descartar un turno en cola
- **Sugerencias de continuación**: aparecen fichas de sugerencia contextuales tras la respuesta de Claude para guiar la conversación
- **Resúmenes de sesión**: resúmenes generados automáticamente para las sesiones terminadas
- Escribe @project para adjuntar el README.md y el árbol de archivos de cualquier proyecto como contexto
- Escribe **@tab** para compartir tu sesión de terminal actual, o **@conversation** para referenciar otro hilo de chat
- Escribe **@context** para inyectar un paquete de contexto, o **@prompt** para insertar una plantilla de prompt guardada
- **Mejora del prompt**: reescritura por IA de tu mensaje en un clic mediante Haiku, para instrucciones más claras antes de enviar
- Interrumpe el streaming a mitad de turno, nombres de pestaña generados automáticamente por el modelo haiku
- Indicador de compactación mostrado durante la compresión del contexto, para saber cuándo ocurre

### Terminales
- Varias terminales de Claude Code por proyecto, con interfaz de pestañas
- Renderizado acelerado por GPU mediante xterm.js + WebGL (con respaldo DOM)
- Alterna entre modo terminal y modo chat en cada pestaña
- Reordenación de pestañas arrastrando, renombrado, notificaciones de escritorio
- Filtrado de terminales por proyecto
- Detección adaptativa de disponibilidad con indicador de estado
- Captura de la salida de la terminal, para que las herramientas de lectura y las herramientas MCP devuelvan realmente lo que se ejecutó

### Navegación
- Elige cómo navegar por los proyectos: una barra de pestañas arriba, o la columna clásica de proyectos al lado
- Se pregunta una vez en el asistente de primer arranque, y se puede cambiar en cualquier momento desde Ajustes

### Archivos
- Una pantalla Archivos dedicada muestra cada archivo tocado en una sesión, con diffs por sesión al estilo de GitHub
- Revisa rápidamente lo que Claude cambió sin salir del contexto del chat
- O mantén el árbol del proyecto anclado junto a la conversación, como estaba antes de la pantalla Archivos

### Cuentas
- Vincula una cuenta de Claude distinta a cada proyecto, con su propio almacén de credenciales aislado
- Cambia de proyecto sin cambiar de cuenta a mano, y sin que el inicio de sesión de un proyecto afecte al de otro
- Uso por cuenta mostrado en Ajustes, y un cambio al alcanzar el límite que continúa la conversación

### Claude Remote Control (claude.ai y móvil)
- Pon una sesión de chat en [claude.ai/code](https://claude.ai/code) y en la app móvil de Claude, para seguirla o controlarla desde el teléfono
- Se decide **por conversación**, nunca globalmente: una sesión se une cuando lo pides en esa pestaña, mediante el botón del pie o el comando `/remote-control`
- Espejo de solo lectura o control completo, a tu elección; prompts, interrupciones y respuestas de permisos vuelven todos al escritorio
- `--rc` opcional en las pestañas de terminal para que las sesiones de CLI también se unan
- Una pestaña **Conectividad → claude.ai** lista cada conversación compartida con una vuelta a su pestaña
- Respeta el interruptor `disableRemoteControl` de los ajustes gestionados de Claude Code, para que una política de organización no pueda levantarse desde la aplicación

### Claude en Chrome
- Deja que las sesiones de chat controlen tu navegador mediante la extensión de Chrome de Claude
- Añade el servidor MCP `claude-in-chrome` y sus 22 herramientas de navegador a la sesión
- Es opcional, y adopta el host de mensajería nativa existente de Claude Code en lugar de sobrescribirlo

### Voz
- Dicta mensajes al chat por micrófono (transcripción con Groq)
- Modo de dictado literal con enrutado a la pestaña activa, para que tus palabras lleguen a la conversación correcta
- Perfil de sesión manos libres para sesiones totalmente por voz
- Pronuncia los nombres de proyecto como los dirías, para que las menciones @ por voz se resuelvan bien

### Gestión de proyectos
- Organiza los proyectos en carpetas anidadas con arrastrar y soltar
- Personaliza cada proyecto con colores e iconos emoji
- Barra de acciones rápidas: comandos de un clic configurables por proyecto (build, test, deploy, scripts propios...)
- Explorador de archivos integrado con vista de árbol, selección múltiple, búsqueda, indicadores de git y renombrado en línea; clic derecho en cualquier archivo para adjuntarlo como contexto al chat actual
- Sistema modular de tipos de proyecto (estándar, FiveM, webapp, Python, API, Minecraft, bot de Discord)
- Ventana de ajustes por proyecto

### Integración con Git
- **Ramas**: cambiar, crear y borrar, con vista de árbol de ramas locales y remotas
- **Sincronización**: pull (rebase), push y merge con detección y resolución de conflictos
- **Panel de cambios**: ver archivos preparados, sin preparar y sin seguimiento, preparar/despreparar y hacer commit
- **Historial de commits**: grafo de commits al estilo IntelliJ renderizado en SVG, filtrado por rama y autor, desplazamiento infinito
- **Cherry-pick y revert**: operaciones avanzadas desde el historial
- **Gestión de worktrees**: crear, cambiar y borrar worktrees de git, con insignia de cambio rápido en la barra de herramientas
- **Gestión de stashes**: guardar, aplicar, extraer e inspeccionar
- **Búsqueda en el historial**: búsqueda de texto completo en el historial de commits
- **Descartar cambios**: descarta rápidamente las ediciones sin preparar, archivo por archivo
- **Enmendar commits**: edita el mensaje o el contenido del último commit antes de subirlo
- **Mensajes de commit por IA**: genera automáticamente mensajes convencionales mediante la API de GitHub Models
- **Pull requests**: crea y consulta PR directamente desde la aplicación

### Integración con GitHub
- Autenticación OAuth Device Flow (segura, sin copiar y pegar tokens)
- **Soporte de GitHub Enterprise**: conexión a instancias autoalojadas de GitHub Enterprise
- **Búsqueda de repositorios en el asistente de clonado**: busca repos de GitHub por nombre sin salir de la aplicación
- **Píldora de estado CI/CD**: estado en vivo de la última ejecución mostrado en la barra de cabecera de la terminal, con un botón para saltar directamente al paso que falló
- Consulta de ejecuciones de CI/CD por repositorio
- Ver, crear y revisar pull requests desde la aplicación; soporte multi-forja (GitHub, GitLab)
- Token almacenado de forma segura mediante keytar (Administrador de credenciales de Windows, Llavero de macOS, libsecret en Linux)

### Torre de control
- Vista en tiempo real de todos los agentes de Claude activos, en todos los proyectos
- Mira qué hace cada agente (herramientas en curso, estado actual, última actividad)
- Vista de rejilla: una tarjeta por sesión abierta, agrupada por proyecto, con miniaturas de terminal en vivo, insignia de modelo y botones de sesión nueva por proyecto
- Filtros y ordenación: por proyecto, por estado, búsqueda de texto, ordenados por tu última interacción
- Vista de foco: maximiza cualquier sesión dentro del panel, con una tira de las demás sesiones del proyecto, títulos de sesión editables y salto de un clic a la vista de Claude
- Las sesiones terminadas siguen resaltadas hasta que las has visto, para que nada se escape
- Interrumpe cualquier sesión en curso directamente desde el panel
- Responde a los avisos de AskUserQuestion sin cambiar a la pestaña de chat
- Herramientas MCP para la supervisión de agentes y la interrupción remota

### Tareas paralelas
- Descompón una funcionalidad en subtareas paralelas y ejecútalas a la vez como agentes de Claude independientes
- Cada tarea se ejecuta en su propio worktree y rama de git, manteniendo el trabajo aislado
- El modo automático deja que Claude decida el número óptimo de tareas paralelas
- Tarjetas de tarea plegables con visor de diff y acceso a terminal por tarea
- Agente de fusión automática: Claude revisa y fusiona las ramas terminadas en tu rama principal
- Estado completo de la ejecución guardado en disco y restaurado al reiniciar

### Repetición de sesión
- Recorre tus sesiones anteriores de Claude Code y repítelas paso a paso
- La vista cronológica muestra todos los prompts, llamadas a herramientas y respuestas en orden
- Control deslizante estilo reproductor de vídeo para saltar a cualquier punto de la sesión
- Tarjetas de preguntas y respuestas que destacan los intercambios para una revisión fácil

### Panel principal
- Tres subvistas: **Resumen**, **Kanban** y **Cronología**
- Resumen: rama actual, commits por delante/por detrás, commits recientes, colaboradores
- Estadísticas de código: líneas por lenguaje, número de archivos, número de commits
- Número de terminales activas
- Seguimiento del uso de la API de Claude con actualización automática
- **Cronología del proyecto**: todos los registros que la aplicación ya guarda, fusionados en una sola vista cronológica — commits, sesiones de Claude, tiempo registrado, ejecuciones de workflows, ejecuciones paralelas y artefactos — filtrable por periodo y por tipo, para que «qué le ha pasado a este proyecto» quepa en una pantalla en vez de seis

### Registro de tiempo
- Detección automática de sesiones por proyecto (15 min de inactividad, detección de suspensión/reanudación)
- Almacenamiento ligero e independiente (`timetracking.json`) con archivos mensuales
- Vista por periodo: hoy, esta semana, este mes, rango personalizado
- Estadísticas: media diaria, racha más larga, gráficos de evolución, sesiones recientes
- Cambio de día a medianoche y puntos de control periódicos

### Hooks
- Se integra con los hooks del CLI de Claude Code para el seguimiento de actividad en tiempo real
- Instalación de un clic en `~/.claude/settings.json` (no destructiva, conserva tus hooks)
- Tipos de hook: PreToolUse, PostToolUse, Notification, SessionStart, Stop, DirectoryAdded (se dispara con `/add-dir`) y más
- Bus de eventos con eventos normalizados para el seguimiento de sesiones, herramientas y subagentes
- Respaldo por lectura de la salida de la terminal cuando los hooks no están disponibles

### Plugins
- Explora y descubre plugins desde las marketplaces configuradas
- Instala plugins directamente desde la aplicación (mediante el CLI de Claude)
- Añade marketplaces de la comunidad por URL de GitHub
- Filtrado por categoría y búsqueda
- Consulta los detalles y el README de un plugin

### Marketplace de skills
- Busca y explora los skills disponibles
- Instalación y desinstalación de un clic
- **Comprobación de actualizaciones**: mira qué skills y plugins instalados tienen versión nueva
- Consulta el README y los detalles de un skill
- Caché local para una navegación rápida

### Biblioteca
- Gestiona **paquetes de contexto** reutilizables (documentos, fragmentos, contenidos de archivos) y **plantillas de prompt**
- Inyecta paquetes de contexto y plantillas de prompt directamente en el chat con las menciones @context y @prompt
- Inserta una plantilla de prompt en cualquier terminal con un clic desde la barra de herramientas
- Genera skills y agentes en segundo plano con el Agent SDK

### Skills y agentes
- Explora y gestiona los skills y agentes de Claude Code
- Consulta los archivos SKILL.md y las configuraciones de agentes
- **Editor con resaltado de sintaxis**: edita archivos de skills y agentes con números de línea y resaltado completo mediante highlight.js
- Carga de skills desde `~/.claude/skills`, los plugins y los recursos incluidos

### Servidores MCP
- Configura, arranca y detén servidores MCP
- Configuración de variables de entorno
- **Registro MCP**: explora y busca en el registro público de servidores MCP

### Sesiones
- Consulta las sesiones de Claude Code por proyecto
- Recorre el historial de sesiones con marcas de tiempo y metadatos
- Fija sesiones arriba y renómbralas en línea desde el diálogo de reanudación
- Modal de reanudación de sesión modernizado, con búsqueda y sesiones fijadas
- Las sesiones muestran el título real de la conversación en lugar de una marca de tiempo, y se pueden buscar por id
- **Mover una sesión a otro proyecto**: reubica una conversación sin perder su historial
- Los nombres de pestaña personalizados quedan bloqueados y ya no los sobrescribe en silencio el nombrado automático

### Memoria y conocimiento global
- Edita los archivos CLAUDE.md globales, de ajustes y propios del proyecto
- Inserción de plantillas para los patrones habituales
- **Conocimiento global**: un almacén de hechos, convenciones y preferencias válido para todos los proyectos, una entrada markdown cada uno, disponible en todas las sesiones
- Fija, activa/desactiva y busca entradas; las activadas se sincronizan en un bloque marcado de `~/.claude/CLAUDE.md`, con vista previa del bloque antes de escribirlo
- Herramientas MCP (`knowledge_list`, `knowledge_write`, `knowledge_search`...) para que Claude pueda leerlas y escribirlas él mismo

### Kanban

## Uso

```bash
# Instalar las dependencias una vez
npm install

# Compilar el renderer y ejecutar la aplicación
npm start

# Ejecutar con las DevTools abiertas
npm run start:dev

# Compilar el renderer en modo watch (desarrollo)
npm run watch
```

> [!TIP]
> Si modificas archivos bajo `src/renderer/`, `src/project-types/` o `renderer.js`, ejecuta `npm run build:renderer` antes de empaquetar o abrir una PR.

## Compilación

```bash
# Compilar para la plataforma actual
npm run build

# Compilar para una plataforma concreta
npm run build:win     # Windows (instalador NSIS)
npm run build:mac     # macOS (DMG)
npm run build:linux   # Linux (AppImage)
```

El instalador se genera en el directorio `build/`.

## Pruebas

```bash
# Ejecutar la suite de pruebas (136 suites de Jest, jsdom)
npm test

# Pruebas en modo watch durante el desarrollo
npm run test:watch

# ESLint sobre main, renderer, shared, servidores MCP y scripts
npm run lint
npm run lint:fix

# Falla si CLAUDE.md se ha desviado del árbol que describe
npm run check:docs

# Prueba de humo con Playwright sobre la aplicación Electron real
npm run test:e2e
```

La CI ejecuta tres trabajos en cada push y cada PR: `lint` (rápido, falla primero),
`test` (Node 18 y 20 en Windows, Linux y macOS) y `e2e` (Ubuntu bajo `xvfb-run`).
El trabajo E2E es **bloqueante**: abre la aplicación real, recorre cada pestaña de la
barra lateral y falla ante cualquier error de consola del renderer o caída del proceso
principal.

`npm run test:e2e` se mantiene fuera de `npm test` porque necesita una pantalla y un
bundle del renderer compilado. Ejecutarlo en local requiere además los módulos nativos
compilados contra la ABI de Electron (`npm run postinstall`).

### Fronteras

La separación main/renderer la impone ESLint, no solo la convención:

- El renderer nunca obtiene `child_process`, `fs`, `net` ni `electron` directamente.
  Habla con el proceso principal únicamente a través de `window.electron_api`.
  **`child_process` no se expone nunca, deliberadamente**: el renderer muestra markdown
  escrito por un modelo, así que un puente al lanzamiento de procesos convertiría
  cualquier inyección de HTML en ejecución de código.
- `contextIsolation: true` y `nodeIntegration: false` en las cinco ventanas.
- La CSP de `index.html` no tiene `'unsafe-inline'`, así que el HTML inyectado en el chat
  no puede ejecutar scripts. Todo el markdown renderizado pasa por `dompurify`.

Si una de estas reglas salta, el arreglo es un handler IPC nuevo, no un `eslint-disable`.
