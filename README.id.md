## Prasyarat

- [Node.js](https://nodejs.org/) 18+
- [Claude Code](https://github.com/anthropics/claude-code) terpasang secara global
- **Windows** 10 atau 11
- **macOS** 12+ (Intel atau Apple Silicon)
- **Linux** Ubuntu 22.04+, Fedora 38+, atau setara
  - AppImage membutuhkan `libfuse2` di Ubuntu 24.04+: `sudo apt install libfuse2`
  - Penyimpanan token GitHub membutuhkan `libsecret`: `sudo apt install libsecret-1-dev gnome-keyring`

## Instalasi

Unduh installer terbaru dari [Releases](https://github.com/Sterll/claude-terminal/releases).

> [!IMPORTANT]
> **Pengguna macOS:** jika muncul *"Claude Terminal is damaged and can't be opened"*, jalankan ini di Terminal:
> ```bash
> xattr -cr /Applications/Claude\ Terminal.app
> ```
> Ini diperlukan karena aplikasinya belum ditandatangani secara digital. Alternatifnya, klik kanan aplikasi → Open.

Atau build dari sumber:

```bash
git clone https://github.com/Sterll/claude-terminal.git
cd claude-terminal
npm install
```

## Fitur

### Antarmuka chat (Claude Agent SDK)
- Antarmuka chat bawaan yang ditenagai Claude Agent SDK, dengan respons streaming
- **Rendering markdown kaya**: diagram mermaid, rumus KaTeX, kode dengan penyorotan sintaks, pohon berkas, papan kanban, blok diff, pratinjau HTML, dan lainnya
- **Kartu izin**: Izinkan, Selalu izinkan, atau Tolak permintaan penggunaan alat; saat aturan `permissions.ask` milik Anda sendiri yang memicu permintaan itu, kartunya menyebut aturan tersebut dan menyembunyikan "Selalu izinkan" agar tidak bisa dilewati dengan satu klik
- **Mode rencana**: tinjau lalu setujui atau tolak rencana agen sebelum dijalankan
- **Blok penalaran**: bagian yang dapat dibuka untuk melihat penalaran Claude
- **Kartu alat**: kartu lipat yang merinci eksekusi alat, lengkap dengan penyegaran alat MCP, pengiriman masukan, dan usulan skill
- **Visualisasi subagen**: pelacakan tugas bersarang untuk agen yang dijalankan; ringkasan tiap subagen menampilkan cabang worktree git-nya dan setiap pergantian model di tengah jalan
- **Widget todo**: daftar tugas persisten di atas kolom input, hilang sendiri setelah selesai
- **Lampiran**: tempel, seret-dan-lepas, atau pilih gambar PNG/JPEG/GIF/WebP (hingga 20 MB), ditambah berkas teks dan PDF
- **Perintah slash**: pelengkapan otomatis perintah (/compact, /clear, /help, skill kustom)
- **Mention @ inline**: kolom input kaya memungkinkan mengetik mention @ tanpa meninggalkan area penulisan pesan
- **Rewind berkas**: kembalikan konteks ke keadaan berkas sebelumnya lewat checkpointing SDK, berguna untuk membatalkan suntingan yang tak diinginkan di tengah sesi
- **Pelacakan biaya**: nama model, jumlah token, dan biaya dalam USD di bilah status
- **Jendela konteks 1J**: konteks diperluas untuk basis kode besar (hanya mode API)
- **Pergantian model dan effort secara dinamis**: pemilih model dibangun langsung dari katalog CLI Claude, jadi model yang baru rilis (misalnya Fable 5.1) muncul otomatis; ganti model dan tingkat effort (low, medium, high, xhigh) di tengah percakapan tanpa memulai sesi baru
- **Model, effort, dan mode izin per percakapan**: tiap tab menyimpan pengaturannya sendiri, sehingga pilihan di satu percakapan tidak pernah bocor ke percakapan berikutnya. Nilai yang tersimpan hanyalah bawaan untuk tab baru, dan diubah lewat baris "Gunakan untuk percakapan baru" di tiap menu
- **Mode izin**: beralih antara bawaan, terima suntingan, rencana, dan lewati izin dari kolom penulisan, di tengah sesi
- **Tingkat premium**: model keluarga Fable ditandai ungu dengan lencana "Premium", label pada tab, dan pemberitahuan saat tab baru mewarisinya, karena keluarga ini memakai batas penggunaannya sendiri
- **Laci tugas latar belakang**: laci lipat khusus sesi berjalan yang menampilkan pekerjaan Claude di latar belakang, agar Anda bisa terus mengobrol
- **Pustaka artefak dan tab Dokumen**: berkas dan cuplikan yang dihasilkan Claude disimpan ke pustaka artefak yang bisa dipakai ulang, dan juga muncul di tab Dokumen per percakapan, dengan panel Artefak khusus yang mendaftar semua yang dipublikasikan untuk proyek itu
- **Pencarian percakapan**: tekan Ctrl+F untuk mencari di transkrip yang sedang berjalan
- **Sematkan percakapan**: jaga sesi penting tetap di atas daftar
- **Fork sesi**: bercabang dari pesan mana pun untuk menjajaki jalur lain; Claude Terminal memberi peringatan alih-alih membuang giliran yang masih mengantre
- **Saran lanjutan**: cip saran sesuai konteks muncul setelah Claude menjawab, untuk memandu percakapan
- **Ringkasan sesi**: ringkasan yang dibuat otomatis untuk sesi yang telah selesai
- Ketik @project untuk melampirkan README.md dan pohon berkas proyek mana pun sebagai konteks
- Ketik **@tab** untuk membagikan sesi terminal Anda saat ini, atau **@conversation** untuk merujuk utas chat lain
- Ketik **@context** untuk menyisipkan paket konteks, atau **@prompt** untuk menyisipkan templat prompt tersimpan
- **Penyempurnaan prompt**: penulisan ulang pesan Anda oleh AI dalam satu klik memakai Haiku, agar instruksinya lebih jelas sebelum dikirim
- Hentikan streaming di tengah giliran, nama tab dibuat otomatis oleh model haiku
- Indikator pemadatan ditampilkan saat konteks sedang dipadatkan, jadi Anda tahu kapan itu terjadi

### Terminal
- Beberapa terminal Claude Code per proyek, dengan antarmuka bertab
- Rendering dipercepat GPU lewat xterm.js + WebGL (cadangan DOM)
- Beralih antara mode terminal dan mode chat pada tiap tab
- Penataan ulang tab dengan seret-lepas, penggantian nama, notifikasi desktop
- Penyaringan terminal berdasarkan proyek
- Deteksi kesiapan adaptif dengan indikator status
- Keluaran terminal direkam, sehingga alat baca terminal dan alat MCP benar-benar mengembalikan apa yang dijalankan

### Navigasi
- Pilih cara Anda menjelajahi proyek: bilah tab proyek di atas, atau kolom proyek klasik di samping
- Ditanyakan sekali di wizard peluncuran pertama, dan bisa diganti kapan saja dari Pengaturan

### Berkas
- Layar Berkas khusus menampilkan setiap berkas yang disentuh dalam satu sesi, dengan diff per sesi bergaya GitHub
- Tinjau cepat apa yang Claude ubah tanpa meninggalkan konteks chat
- Atau biarkan pohon proyek tertambat di samping percakapan, seperti sebelum ada layar Berkas

### Akun
- Ikat akun Claude terpisah ke tiap proyek, dengan penyimpanan kredensial terisolasi sendiri
- Ganti proyek tanpa mengganti akun secara manual, dan tanpa login satu proyek memengaruhi proyek lain
- Penggunaan per akun ditampilkan di Pengaturan, plus pergantian saat batas tercapai yang meneruskan percakapan

### Claude Remote Control (claude.ai dan ponsel)
- Tempatkan sesi chat di [claude.ai/code](https://claude.ai/code) dan aplikasi ponsel Claude, agar bisa Anda ikuti atau kendalikan dari ponsel
- Ditentukan **per percakapan**, tidak pernah global: satu sesi bergabung saat Anda memintanya di tab itu, lewat tombol di footer atau perintah `/remote-control`
- Cermin baca-saja atau kendali penuh, sesuai pilihan Anda; prompt, interupsi, dan jawaban izin semuanya kembali ke desktop
- `--rc` opsional di tab terminal agar sesi CLI ikut bergabung
- Tab **Konektivitas → claude.ai** mendaftar setiap percakapan yang dibagikan, dengan jalan kembali ke masing-masing tab
- Menghormati sakelar `disableRemoteControl` pada managed settings Claude Code, sehingga kebijakan organisasi tidak bisa dibatalkan dari aplikasi

### Claude di Chrome
- Biarkan sesi chat mengendalikan peramban Anda lewat ekstensi Chrome milik Claude
- Menambahkan server MCP `claude-in-chrome` beserta 22 alat peramban ke sesi
- Bersifat opt-in, dan mengadopsi native messaging host milik Claude Code yang sudah ada alih-alih menimpanya

### Suara
- Diktekan pesan ke chat lewat mikrofon (transkripsi Groq)
- Mode dikte verbatim dengan pengarahan ke tab aktif, agar kata-kata Anda mendarat di percakapan yang benar
- Profil sesi bebas-tangan untuk sesi yang sepenuhnya dijalankan dengan suara
- Melafalkan nama proyek sebagaimana Anda mengucapkannya, agar mention @ lewat suara terselesaikan dengan benar

### Manajemen proyek
- Atur proyek dalam folder bersarang dengan seret-lepas
- Sesuaikan tiap proyek dengan warna dan ikon emoji
- Bilah Aksi Cepat: perintah satu klik yang bisa dikonfigurasi per proyek (build, test, deploy, skrip kustom...)
- Penjelajah berkas bawaan dengan tampilan pohon, pilihan ganda, pencarian, indikator status git, dan penggantian nama inline; klik kanan berkas mana pun untuk melampirkannya sebagai konteks di chat berjalan
- Sistem tipe proyek modular (standar, FiveM, webapp, Python, API, Minecraft, bot Discord)
- Jendela pengaturan per proyek

### Integrasi Git
- **Cabang**: beralih, buat, hapus, dengan tampilan pohon cabang lokal dan remote
- **Sinkronisasi**: pull (rebase), push, merge dengan deteksi dan penyelesaian konflik
- **Panel perubahan**: lihat berkas staged, unstaged, dan untracked, stage/unstage, lalu commit
- **Riwayat commit**: grafik commit bergaya IntelliJ yang dirender SVG, penyaringan per cabang dan penulis, gulir tak terbatas
- **Cherry-pick dan revert**: operasi commit lanjutan dari riwayat
- **Manajemen worktree**: buat, beralih, dan hapus worktree git, dengan lencana pergantian cepat di bilah alat
- **Manajemen stash**: simpan, terapkan, pop, dan periksa
- **Pencarian riwayat**: pencarian teks penuh di seluruh riwayat commit
- **Buang perubahan**: buang cepat suntingan yang belum di-stage, per berkas
- **Amend commit**: sunting pesan atau isi commit terakhir sebelum push
- **Pesan commit oleh AI**: hasilkan pesan commit konvensional otomatis lewat GitHub Models API
- **Pull request**: buat dan lihat PR langsung dari aplikasi

### Integrasi GitHub
- Autentikasi OAuth Device Flow (aman, tanpa salin-tempel token)
- **Dukungan GitHub Enterprise**: terhubung ke instans GitHub Enterprise yang di-host sendiri
- **Pencarian repositori di wizard clone**: cari repo GitHub berdasarkan nama tanpa keluar dari aplikasi
- **Pil status CI/CD**: status langsung dari run terbaru ditampilkan di bilah header terminal, dengan tombol untuk langsung melompat ke langkah yang gagal
- Lihat run CI/CD per repositori
- Lihat, buat, dan tinjau pull request dari aplikasi; dukungan multi-forge (GitHub, GitLab)
- Token disimpan dengan aman lewat keytar (Windows Credential Manager, macOS Keychain, libsecret di Linux)

### Menara kendali
- Ikhtisar waktu nyata semua agen Claude yang aktif, di seluruh proyek
- Lihat apa yang sedang dikerjakan tiap agen (alat yang berjalan, status saat ini, aktivitas terakhir)
- Tampilan grid: satu kartu per sesi terbuka, dikelompokkan per proyek, dengan pratinjau terminal langsung, lencana model, dan tombol sesi baru per proyek
- Filter dan pengurutan: per proyek, per status, pencarian teks, diurutkan berdasarkan interaksi terakhir Anda
- Tampilan fokus: perbesar sesi mana pun di dalam panel, dengan deretan sesi lain milik proyek itu, judul sesi yang bisa disunting, dan lompatan satu klik ke tampilan Claude
- Sesi yang selesai tetap disorot sampai Anda melihatnya, agar tidak ada pekerjaan yang terlewat
- Hentikan sesi yang sedang berjalan langsung dari panel
- Jawab prompt AskUserQuestion tanpa berpindah ke tab chat
- Alat MCP untuk pemantauan agen dan interupsi jarak jauh

### Tugas paralel
- Uraikan sebuah fitur menjadi subtugas paralel dan jalankan serentak sebagai agen Claude terpisah
- Tiap tugas berjalan di worktree dan cabang git-nya sendiri, sehingga pekerjaannya terisolasi
- Mode otomatis membiarkan Claude menentukan jumlah tugas paralel yang optimal
- Kartu tugas yang bisa dilipat, dengan penampil diff dan akses terminal per tugas
- Agen penggabung otomatis: Claude meninjau dan menggabungkan cabang yang selesai ke cabang utama Anda
- Status eksekusi lengkap disimpan ke disk dan dipulihkan saat aplikasi dimulai ulang

### Pemutaran ulang sesi
- Telusuri sesi Claude Code lama dan putar ulang langkah demi langkah
- Tampilan lini masa menunjukkan semua prompt, panggilan alat, dan respons secara berurutan
- Penggeser bergaya pemutar video untuk melompat ke titik mana pun dalam sesi
- Kartu tanya-jawab menyorot pertukaran pertanyaan dan jawaban agar mudah ditinjau

### Dasbor
- Tiga subtampilan: **Ikhtisar**, **Kanban**, dan **Lini masa**
- Ikhtisar: cabang saat ini, commit di depan/di belakang, commit terbaru, kontributor
- Statistik kode: baris per bahasa, jumlah berkas, jumlah commit
- Jumlah terminal aktif
- Pemantauan penggunaan API Claude dengan penyegaran otomatis
- **Lini masa proyek**: semua catatan yang sudah disimpan aplikasi, digabung menjadi satu tampilan kronologis — commit, sesi Claude, waktu terlacak, run workflow, run paralel, dan artefak — bisa disaring per periode dan per jenis, sehingga "apa yang terjadi pada proyek ini" cukup satu layar, bukan enam

### Pelacakan waktu
- Deteksi sesi otomatis per proyek (batas diam 15 menit, deteksi tidur/bangun)
- Penyimpanan ringan terpisah (`timetracking.json`) dengan arsip bulanan
- Tampilan per periode: hari ini, minggu ini, bulan ini, rentang kustom
- Statistik: rata-rata harian, rentetan terpanjang, grafik perkembangan, sesi terbaru
- Pergantian hari di tengah malam dan titik simpan berkala

### Hooks
- Terintegrasi dengan hook CLI Claude Code untuk pelacakan aktivitas waktu nyata
- Pemasangan satu klik ke `~/.claude/settings.json` (tidak merusak, mempertahankan hook Anda)
- Jenis hook: PreToolUse, PostToolUse, Notification, SessionStart, Stop, DirectoryAdded (terpicu oleh `/add-dir`), dan lainnya
- Bus peristiwa dengan peristiwa yang dinormalkan untuk pelacakan sesi, alat, dan subagen
- Cadangan berupa pembacaan keluaran terminal saat hook tidak tersedia

### Plugin
- Jelajahi dan temukan plugin dari marketplace yang dikonfigurasi
- Pasang plugin langsung dari aplikasi (lewat CLI Claude)
- Tambahkan marketplace komunitas lewat URL GitHub
- Penyaringan kategori dan pencarian
- Lihat detail dan README sebuah plugin

### Marketplace skill
- Cari dan jelajahi skill yang tersedia
- Pemasangan dan penghapusan satu klik
- **Pemeriksaan pembaruan**: lihat skill dan plugin terpasang mana yang punya versi baru
- Lihat README dan detail sebuah skill
- Cache lokal untuk penjelajahan yang cepat

### Pustaka
- Kelola **paket konteks** yang bisa dipakai ulang (dokumen, cuplikan, isi berkas) dan **templat prompt**
- Sisipkan paket konteks dan templat prompt langsung ke chat lewat mention @context dan @prompt
- Sisipkan templat prompt ke terminal mana pun dengan satu klik dari bilah alat
- Hasilkan skill dan agen di latar belakang memakai Agent SDK

### Skill dan agen
- Jelajahi dan kelola skill serta agen Claude Code
- Lihat berkas SKILL.md dan konfigurasi agen
- **Editor dengan penyorotan sintaks**: sunting berkas skill dan agen dengan nomor baris dan penyorotan penuh lewat highlight.js
- Memuat skill dari `~/.claude/skills`, plugin, dan sumber daya bawaan

### Server MCP
- Konfigurasi, jalankan, dan hentikan server MCP
- Konfigurasi variabel lingkungan
- **Registri MCP**: jelajahi dan cari di registri publik server MCP

### Sesi
- Lihat sesi Claude Code per proyek
- Telusuri riwayat sesi dengan stempel waktu dan metadata
- Sematkan sesi ke atas dan ganti namanya secara inline dari dialog lanjutkan
- Modal lanjutkan sesi yang dimodernkan, dengan pencarian dan sesi tersemat
- Sesi menampilkan judul percakapan yang sebenarnya alih-alih stempel waktu, dan bisa dicari berdasarkan id
- **Pindahkan sesi ke proyek lain**: relokasi percakapan tanpa kehilangan riwayatnya

## Pengujian

```bash
# Jalankan seluruh pengujian (136 suite Jest, jsdom)
npm test

# Pengujian mode watch selama pengembangan
npm run test:watch

# ESLint untuk main, renderer, shared, server MCP, dan skrip
npm run lint
npm run lint:fix

# Gagal jika CLAUDE.md sudah melenceng dari pohon yang dijelaskannya
npm run check:docs

# Uji asap Playwright terhadap aplikasi Electron yang sebenarnya
npm run test:e2e
```

CI menjalankan tiga job pada setiap push dan PR: `lint` (cepat, gagal duluan),
`test` (Node 18 dan 20 di Windows, Linux, dan macOS), dan `e2e` (Ubuntu di bawah
`xvfb-run`). Job E2E bersifat **memblokir**: ia membuka aplikasi sungguhan, menyusuri
setiap tab bilah samping, dan gagal pada kesalahan konsol renderer atau kegagalan
proses utama apa pun.

`npm run test:e2e` sengaja tidak masuk `npm test` karena membutuhkan tampilan dan
bundle renderer yang sudah dibangun. Menjalankannya secara lokal juga memerlukan modul
native yang dibangun untuk ABI Electron (`npm run postinstall`).

### Batasan

Pemisahan main/renderer ditegakkan oleh ESLint, bukan sekadar konvensi:

- Renderer tidak pernah mendapat `child_process`, `fs`, `net`, atau `electron` secara
  langsung. Ia berbicara ke proses utama hanya lewat `window.electron_api`.
  **`child_process` sengaja tidak pernah diekspos**: renderer menampilkan markdown yang
  ditulis model, jadi jembatan ke peluncuran proses akan mengubah injeksi HTML apa pun
  menjadi eksekusi kode.
- `contextIsolation: true` dan `nodeIntegration: false` di kelima jendela.
- CSP di `index.html` tidak memiliki `'unsafe-inline'`, sehingga HTML yang disuntikkan ke
  chat tidak bisa menjalankan skrip. Semua markdown yang dirender melewati `dompurify`.

Jika salah satu aturan ini terpicu, perbaikannya adalah handler IPC baru, bukan
`eslint-disable`.
